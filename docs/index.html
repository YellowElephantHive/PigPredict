BEHIND THE COLOR

Manufacturing knowledge meets inverse design.

The network learns the forward relationship between a recipe and its color. Inverse search turns that relationship into a formulation tool.

◧

Start with process data

Measured Lab values, dye concentrations and fabric types form the foundation. Historical recipes supply relevant dye combinations.

⌘

Learn recipe to color

A 10-layer neural decoder maps 44 dye channels and 3 fabric indicators to L*, a* and b*.

◎

Search color to recipe

Keep the trained weights fixed. Optimize the dye concentrations, then rank candidates by their predicted color difference.

Interactive runtime
JavaScript · Web Worker · Django

The refreshed application uses the archived model weights with a deterministic, bounded inverse solver. A Web Worker keeps the interface responsive; numeric checks compare browser predictions with the original HDF5 weights.
